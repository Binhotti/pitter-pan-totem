# database/seeds/

> Arquivo de documentação da pasta — parte da arquitetura oficial do sistema Pitter Pan.
> Nenhum arquivo de funcionalidade foi criado aqui nesta etapa.

**Objetivo:**
Dados de exemplo/iniciais para ambiente de desenvolvimento e testes (ex.: alguns balões e pedidos fictícios para testar telas sem precisar cadastrar tudo manualmente).

**Arquivos permitidos:**
Scripts/arquivos que inserem dados de exemplo.

**Arquivos proibidos:**
Dados reais de clientes, dados de produção.

**Dependências:**
database/schema/ (a estrutura precisa existir antes dos dados).

**Quando usar:**
Ao configurar um ambiente de desenvolvimento novo, ou ao escrever testes que precisam de dados pré-existentes.
