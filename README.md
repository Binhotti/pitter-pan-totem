# Totem Pitter Pan


## Estrutura

- `index.html`: telas do sistema
- `css/`: estilos e responsividade
- `js/data.js`: temas, modelos, cores e preços
- `js/balloon.js`: geração da prévia em SVG
- `js/app.js`: navegação e estado do pedido
- `assets/logo-pitter-pan.png`: logotipo

## Ajustar preços

Altere `basePrice` em `js/data.js`.
