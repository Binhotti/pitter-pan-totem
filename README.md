# Totem Pitter Pan

Abra o arquivo `index.html` no navegador.

Para desenvolver com atualização automática, use a extensão Live Server no VS Code.

## Estrutura

- `index.html`: telas do sistema
- `css/`: estilos e responsividade
- `js/data.js`: temas, modelos, cores e preços
- `js/balloon.js`: geração da prévia em SVG
- `js/app.js`: navegação e estado do pedido
- `assets/logo-pitter-pan.png`: logotipo

## Ajustar preços

Altere `basePrice` em `js/data.js`.

## Atualização visual

A tela inicial e a seleção de ocasiões usam uma organização vertical e touch-first, adequada para adaptação futura em totem.
